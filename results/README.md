# Results

All JSON outputs behind the tables and figures of the letter, generated by
`scripts/10_revision/` (see the repository README for the command map).

| File | Produced by | Paper item |
|---|---|---|
| `sardet_cfar.json`, `sarship_cfar.json` | `cfar_eval.py` | Table I and Fig. 2 — false-alarm stability at 12 pre-specified targets, with 200-resample bootstrap CIs and 20-permutation placebo |
| `numbers.json` | `run_main_eval.py` + `make_tables.py` | Table II (F1-balanced results, `baseline_rows` / `adaptive_f1_rows`), Table III (controls, `control_*`, `oracle`), Sec. III-F (transfer, `transfer_*`) |
| `curves_sardet.json`, `curves_sarship.json` | `export_curves.py` | Fig. 3 — per-bin F1 and gated AP vs. threshold |
| `*_kfold.json` | `kfold_cv.py` | Sec. III-D — 10-fold cross-validation |
| `*_ksweep.json` | `sweep_k.py` | Sec. III-D — dilation sweep |
| `*_proxy_report.json` | `recompute_proxy.py` | Sec. III-E — proxy validation statistics |
| `*_main.json` | `run_main_eval.py` | full per-strategy detail behind `numbers.json` |

Fitted quantities (bin edges, per-bin thresholds, linear coefficients) are
stored inside `numbers.json` under the corresponding dataset key.
